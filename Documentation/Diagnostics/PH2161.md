## Introduction

Enforces PascalCase naming for test methods by rejecting names that contain underscores.

## How to solve

Rename the test method to use PascalCase without underscores. The code fixer automatically removes underscores and capitalizes each segment.

## Example

Code that triggers a diagnostic:
``` cs
[TestMethod]
public void Method_Scenario_Expected() { }
```

And the replacement code:
``` cs
[TestMethod]
public void MethodScenarioExpected() { }
```

## Configuration

This analyzer does not offer any special configuration. The general ways of [suppressing](https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/suppress-warnings) diagnostics apply.

This rule is mutually exclusive with PH2162 (EnforceUnderscoresInTestMethodName). Enable only one.
