# PH2162: Enforce underscores in test method name

| Property | Value  |

## Introduction

Enforces underscore-separated naming for test methods by requiring at least one underscore in the method name.

## How to solve

Rename the test method to include underscores separating logical parts of the name.

## Example

Code that triggers a diagnostic:
``` cs
[TestMethod]
public void MethodScenarioExpected() { }
```

And the replacement code:
``` cs
[TestMethod]
public void Method_Scenario_Expected() { }
```

## Configuration

This analyzer does not offer any special configuration. The general ways of [suppressing](https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/suppress-warnings) diagnostics apply.

This rule is mutually exclusive with PH2161 (AvoidUnderscoresInTestMethodName). Enable only one.
